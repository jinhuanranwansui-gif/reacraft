# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, in short:

**Be straight with people.** Argue about the code, the design and the evidence — not about the
person. Disagreement is welcome and expected here; contempt is not.

Concretely, in issues and pull requests:

- Say what you observed before you say what you concluded.
- If you are wrong, say so in one sentence and move on. Nobody needs an apology essay.
- Do not use a security tool as a pretext to attack a person, a project or a company.
- A maintainer may close a thread that has stopped being about the work.

Reports about behaviour go to the repository maintainer through a private security advisory or a
direct message. Reports about the software go in an issue.

Maintainers are held to the same standard, and to one more: they answer with a decision, not a mood.
